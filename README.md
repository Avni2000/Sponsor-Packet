# Wisco Humanoids Sponsorship Packet

### Notes:
The original claude-design-generated HTML was encoded in Base64 and Gzipped. `decode.py` undoes that so as to make the raw html more accessible (and gets rid of some nuisance HTML wrappers in the meantime). Run:

```bash
./decode.py "WiscoHumanoids Sponsorship Packet.html"
```

to regenerate the output
